    System Architecture & Theoretical Mapping

    Academic curriculum integration mapping timetabling logic to core computer science fundamentals.

    Operating Systems (OS)

    Resource Management
    • Mutual Exclusion (Mutex): Physical rooms and faculty members represent non-shareable resources. No two concurrent sessions may lock the same room or faculty resource during identical quantum slices.
    • Deadlock Avoidance: Minimum Remaining Values (MRV) forward checking enforces state safety invariants similar to the Banker’s Algorithm, preventing search execution deadlocks.
    • Quantum Discretization: Operating hours are segmented into uniform time quanta with institutional lunch intervals acting as protected kernel break boundaries.
    • Concurrency & Multiprogramming: Practical lab batches execute concurrently across distinct partitioned laboratory rooms during the same operational time slice.
    Code Reference: constraints.py (lines 60-90)

    Database Systems (DBMS)

    Relational Model & ACID
    • 3NF Normalization: Entities (Rooms, Faculty, Sections, Batches, Courses) adhere to Third Normal Form with unique keys and referential integrity.
    • ACID Transaction Rollback: Assign / Unassign backtracking cycles behave as atomic transactions. Downstream constraint violations trigger clean rollback without partial state corruption.
    • Relational Constraints: Domain constraints on room types, entity integrity on primary identifiers, and referential constraints across parent sections.
    • Shadow Paging / WAL: database.py executes atomic filesystem replacement (os.replace) via temporary storage files to ensure persistence crash safety.
    Code Reference: models.py, database.py, scheduler.py (_assign/_unassign)

    Design & Analysis of Algorithms (DAA)

    CSP & Heuristic Search
    • CSP Formulation: Formal (X, D, C) tri-tuple formulation where variables X are academic sessions, domains D are slot-room assignments, and C are hard consistency constraints.
    • State Space Tree Search: Depth-First recursive exploration of viable assignment branches with intelligent backtracking.
    • MRV (Fail-First) Heuristic: Multi-period practical lab sessions and variables with the fewest remaining candidate rooms are evaluated first to minimize branching factors.
    • Complexity Analysis: Theoretical worst-case exponential O(d^n) reduced to empirical sub-50ms execution via forward consistency pruning.
    Code Reference: scheduler.py (solve, _backtrack)

    Discrete Mathematical Structures (DMS)

    Graph & Set Theory
    • Cartesian Products: Variable domains are derived from the Cartesian product: WorkingDays x TimeSlots x SuitableRooms.
    • Bipartite Matching: Assigning session requirements to available room-time combinations under degree constraints.
    • Graph Vertex Coloring: Sessions correspond to vertices, resource conflicts (shared instructor, room, or section) form edges, and time slots represent distinct colors. Solvable when chromatic number chi(G) <= total slots.
    • Predicate Logic: Institutional rules articulated as universal and existential propositions across all assignment tuples.
    Code Reference: constraints.py, time_slots.py

    Engine Comparison Matrix: CSP Backtracking vs. Alternatives

    Architectural evaluation of academic timetabling algorithmic engines
    Approach Mechanism Core Strengths Evaluation for Academic Scheduling
    CSP + Backtracking (Selected) Deterministic depth-first search with MRV pruning and forward checking Guarantees 100% hard constraint satisfaction; mathematically proves infeasibility; fully explainable Selected engine. Pure native Python with zero commercial binary dependencies.
    Genetic Algorithms (GA) Stochastic population crossover and mutation evaluated against fitness metrics Effective for multi-objective optimization across soft preferences Hard constraints modeled as soft penalties; frequently yields 1-2 critical conflicts; non-deterministic.
    Integer Linear Programming (ILP) Simplex / Branch-and-bound optimization solver (Gurobi, CPLEX) Provably optimal for strictly linear mathematical formulations Requires external proprietary C solvers; complex formulation for contiguous multi-hour practicals.
    CPU Scheduling (RR, SJF, FCFS) Priority / Queue-based single-resource dispatcher Efficient for 1-dimensional CPU core dispatching Inapplicable problem space: CPU scheduling is 1D time dispatching, whereas timetabling is 3D multi-resource locking.
